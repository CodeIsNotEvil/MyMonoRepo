# 2026-09-28

- [[launchheim]] now shows its "LH" logo in the title bar and taskbar on Linux and Windows. Qml.Net
  exposes neither `QGuiApplication::setWindowIcon` nor `setDesktopFileName`, so a small native
  library (`native/app_icon.cpp`) makes both calls. The csproj builds it with g++ on Linux and
  `packaging/windows/build.ps1` builds it with MSVC. Checked on the owner's Plasma 6: XWayland now
  carries all seven `_NET_WM_ICON` sizes, and KWin sees the Wayland window as `launchheim` (the
  installed old build reported `local.cine.LaunchHeim`). The Windows side is only checked by the
  *LaunchHeim Windows* workflow, whose smoke test fails if the log says "no app icon".
- The window icon uses PNGs (`packaging/icons`, rendered from the SVG per the raster rule of
  2026-09-27), because PNG is built into QtGui while SVG and ICO need image plugins.
