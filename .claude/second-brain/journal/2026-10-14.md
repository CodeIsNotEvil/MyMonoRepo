# 2026-10-14

- LaunchHeim (branch `launchheim-steam-launch-options`): a command line (`play`, `steam`, `list`,
  `help`) and Steam's own Play button starting the last play through `launchheim steam %command%` in
  Valheim's launch options ([[0015-launchheim-steam-launch-options-wrap-steams-command]]).
- Steam's Linux launch config for Valheim is plain `valheim.x86_64` (an OpenGL entry adds
  `-force-glcore`); `start_Valheim.sh` in the owner's game folder is a leftover of their own.
- LaunchHeim (.NET) runs fine as a wrapper inside Steam's scout runtime (`steam-runtime/run.sh`) with
  the overlay preloaded; the overlay only prints "pid ... skipping destruction (fork without exec?)".
- Gotcha: the Bash tool's shell here is zsh, which doesn't word-split `$VAR` into a command; put
  multi-word env prefixes in a bash script or an array.
- Review follow-up: Copy didn't work on Windows. Cause: no `[STAThread]` on `Program.Main`, so Qt's
  OLE clipboard never initialised; proved by a new clipboard check in the Windows smoke test failing
  before the fix (see Gotchas in [[launchheim]]). All Copy buttons go through `Clipboard.qml` now.
- Text in every text field sat 4 px high (Material's asymmetric padding); fixed in `LhTextField` and
  `SearchField`.
- LaunchHeim (branch `launchheim-instant-start`): "Start instantly" per server or world, a BepInEx
  plugin that presses Start in Valheim's menus ([[0016-launchheim-instant-start-plugin]]). The owner
  chose a per-destination switch; vanilla then runs with LaunchHeim's own BepInEx.
- Valheim 1.0.17 is on Unity 6 (6000.0.75). nuget.bepinex.dev has matching `UnityEngine.Modules` and
  `BepInEx.Core` 5.4.21, enough to compile a plugin without the game.
- Branch `launchheim-browse-remove-and-achievements`: a red remove button on installed mods' Browse
  cards, and "Keep Steam achievements when playing with mods" through the dev command's character key
  ([[0017-launchheim-keeps-achievements-with-the-games-own-switch]]). The plugin was renamed to
  GamePlugin before 0.7.0 shipped.
- 0.7.0 released; modded starts from Steam failed on the owner's machine (Steam Linux Runtime chain,
  Doorstop preloaded into the container launcher). Hotfix 0.7.1 puts Doorstop in front of the game
  inside Steam's command; reproduced and verified in the real container with `/bin/echo` and a
  stand-in game. `launchheim steam %command%` in a terminal now explains itself instead of crashing.
