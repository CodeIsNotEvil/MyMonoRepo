# 2026-10-04

- [[launchheim]] direct play: a Play page that lists Valheim's own servers (Favorites and Recent) and
  worlds, and starts one with a character and setup remembered per server or world. Decompiled the
  game to see what the client supports: `+connect` and `-password` for servers, PlayerPrefs `profile`
  and `world` for the menus' selection, and no way to load a world from the command line. Recorded as
  [[0010-launchheim-direct-play-uses-the-games-own-options]]. Gotchas (world folders, dialogs in
  screenshots, `loginusers.vdf`) are on the project note. Not tried in a real game yet.
- [[launchheim]] Play page pictures: clicking a server's or world's tile picks an image for it, copied
  into the data folder under a new random name per pick (QML's `Image` caches by URL). Kept in
  `playImages`, apart from `playChoices`, so a picture can be set before the first launch. Prepared
  the 0.4.0 release with direct play and the pictures.
- [[launchheim]] Windows CI failed on the new saves tests: raw-string fixtures got CRLF from the
  autocrlf checkout, and expected paths used `/`. Normalized both. Added players online per server
  over A2S. A live server showed that Valheim reports the count but empty player names, so names
  can't be shown. The owner wants one PR per feature, with follow-ups pushed to it.
- [[launchheim]] The sidebar's Play button replays the last launch (`lastPlay`: a destination key, else
  an instance, else vanilla) instead of always starting vanilla. Sidebar labels put the destination
  first, because the card elides the end.
- Site: the download page mixed GroceryTracker and LaunchHeim. Commit 11b6983 (2026-10-01, the Arch
  install-from-file change) had deleted 97 lines of `download.html` between GroceryTracker's
  `<!-- if:gt_release -->` and LaunchHeim's install steps, and the leftover markers still balanced.
  Restored them, and `build.py` now fails on in-page links without a target or unclosed sections.
  Lesson: check a large deletion in a diff stat (`127 ++---`) against what the commit says it does.
