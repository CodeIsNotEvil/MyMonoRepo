# 2026-09-30

- [[launchheim]] now makes sure Steam is running and logged in before it starts Valheim. Without
  Steam the game showed only a black window. Readiness is a running `steam` process plus a non-zero
  `ActiveProcess/ActiveUser` (Windows registry, or `registry.vdf` on Linux). If Steam isn't running,
  LaunchHeim starts it with `-silent`, waits up to 3 minutes, and then waits 5 more seconds for the
  Steam API to settle. On the owner's machine, with Steam closed, the detection reported `NotRunning`.
  The start-and-wait path still needs a manual test on Linux and Windows.
