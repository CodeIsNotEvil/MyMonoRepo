# 2026-09-30

- [[launchheim]] now makes sure Steam is running and logged in before it starts Valheim. Without
  Steam the game showed only a black window. If Steam isn't running, LaunchHeim starts it with
  `-silent`, waits up to 3 minutes for the login, then 5 more seconds for the Steam API to settle.
- The first version waited on `ActiveProcess/ActiveUser` in `registry.vdf` and hung in the owner's test:
  current Linux Steam doesn't write that key. Linux now reads the last state in
  `logs/connection_log.txt` (`Logged On` / `Logging Off` / `Logged Off`), which must be newer than the
  running `steam` process so a crash's leftover doesn't count. Checked on CachyOS: with Steam closed,
  the probe started Steam and was ready 8 s later. The Windows registry path is still untested.
- Third-party license compliance for [[launchheim]]. Inventory: Qt 5.15.2 DLLs, ANGLE and Mesa's
  `opengl32sw.dll` (Windows zip only), Qml.Net, NetNativeLibLoader (LGPL, a surprise), SharpCompress,
  Markdig, Newtonsoft.Json, the .NET runtime (Windows zip and the self-contained .deb), the VC++
  runtime (Windows) and Kode Mono. All of it now ships with notices and full texts. The About page
  carries the LGPL section 4 notice for Qt, and the download page links Qt's source next to the zip.
  The released v0.1.0 artifacts predate this and need a new release to comply.
- Prepared the 0.2.0 releases of [[grocerytracker]] and [[launchheim]] with per-app changelogs
  ([[0008-changelog-per-app]]). GroceryTracker had no changes since 0.1.0, so the owner chose to give
  it a visible version (Settings → About) as its 0.2.0 change. Found on the way: LaunchHeim's About
  page and User-Agent said 1.0.0, because `<Version>` sat only in the Desktop csproj while `AppInfo`
  lives in Core. Both apps now set it in `Directory.Build.props`, with a test against that file.

- Made animated profile pictures from `C-logo.svg` with `Scripts/glint_gif.py`:
  `Assets/C-logo-glint-{1024,512,256,128,64,32}.gif`, each rendered from the SVG. The owner wanted
  1024 px as the largest, not GitHub's maximum (github/docs `profile-reference.md`: PNG/JPG/GIF, under
  1 MB, smaller than 3000 x 3000). Findings: the glint is stepped into 24 flat levels, and each frame
  stores only what changed (`magick -layers OptimizeTransparency`). A 2999 px test was 1.5 MB before
  that and 621 kB after. Pillow's `quantize(palette=...)` maps colours through a reduced-precision
  cache, so the orange came out as 218,87,50; the script matches colours exactly with NumPy. The
  palette needs one free slot, or ImageMagick re-quantises when it adds transparency; that made the
  background lighter at 64 and 32 px. The background is solid `#181614` (the site's dark), because
  GIF's 1-bit transparency leaves jagged edges in GitHub's circle crop.
- All C logo files now live in `Assets/c-logo/`: the SVG (the source), transparent PNGs from 1024 to
  32 px for sites without SVG support, and the glint GIFs. Its README lists the files and the commands
  that regenerate them.
