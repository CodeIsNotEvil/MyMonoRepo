# 2026-10-01

- The [[app-site]]'s Arch instructions for [[launchheim]] (`sudo pacman -U <url>`) never worked: pacman
  requires a signature for packages it downloads itself and fails on the missing `.sig`. The page, the
  release notes and `packaging/README.md` now say to download the file, check it with `sha256sum -c`
  and install the local file. Checked with the 0.3.0 package: the hash matches and
  `pacman -U --print ./file` accepts it.
- The download page now shows each LaunchHeim file's SHA-256 (taken from the release API's `digest`),
  with a `sha256sum -c` line for Linux and a `Get-FileHash` line for Windows. The release notes get a
  checksum block from the release workflow.
- Open: signing the Arch package would make `pacman -U <url>` work, but users would have to import and
  trust the key first, which is more friction than the checksum.
