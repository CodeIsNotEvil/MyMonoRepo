# 2026-10-16

- Planned a new project, working name Druckwerk: MIT C# libraries on NuGet for barcodes, QR codes,
  labels, receipts and vector graphics, exporting SVG/PDF/PNG/JPEG/TIFF and printing on wired printers
  on Windows and Linux; later a server connector and a Blazor UI for many connectors ([[druckwerk]]).
- Nothing decided yet. The plan lists proposed decisions (licence policy, package split, pure managed
  core shared with the browser, raster-first printing) and seven open questions for the owner.
- Licences checked for the obvious candidates: ImageSharp/SixLabors.Fonts (Six Labors Split License)
  and QuestPDF (community licence) are not free for everyone, so they're out. SkiaSharp (MIT) is the
  only native dependency, and only in the raster/PDF package.
- nuget.org had no packages named `Druckwerk` or `CINE` on 2026-10-16 (checked through
  `api.nuget.org/v3-flatcontainer`; the search host `azuresearch-usnc.nuget.org` is blocked from the
  cloud sandbox).
