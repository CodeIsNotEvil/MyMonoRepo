# 2026-10-08

- Created a self-signed Authenticode certificate for [[launchheim]]'s Windows build
  ([[0012-launchheim-windows-self-signed-code-signing]]) and backed up the `.pfx` and `.cer` next to the
  APK key in `/mnt/BackupHDD/KeyBackups/LaunchHeim/` (README.txt there has the thumbprint and restore
  steps). The password lives only in the password manager and the GitHub secret.
- Gotcha: `openssl pkcs12 -passin file:X -passout file:X` with the same file reads line 1 for input and
  line 2 for output, so a one-line password file fails ("Error reading password from BIO"). Use
  `env:VAR` for both.
- Next: set `LAUNCHHEIM_WINDOWS_SIGNING_PFX` / `_PASSWORD`, run the Windows workflow once to see signtool
  sign on the runner, and mention the signature in the next release's CHANGELOG section.
