# 2026-09-27

- Switched the GroceryTracker UI font to Kode Mono. It's self-hosted as one variable woff2
  (`wwwroot/fonts/`, 400–700, SIL OFL 1.1) instead of loaded from Google Fonts, because the app
  promises no CDN fetches offline. Gotcha: the published service worker's asset filter only matched
  `.woff`, so a `.woff2` would never have been cached offline. It now matches `\.woff2?$`.
- Unified the repo's logos: Kode Mono Bold in `#DE5833`, transparent background, glyphs as paths.
  `Assets/C-logo.svg` (repo-level, not GroceryTracker's), GroceryTracker's "GT" (the SVG plus
  `icon-192/512.png` and `favicon.ico` rendered from it) and LaunchHeim's "LH" (`launchheim.svg`
  and `.ico`, replacing the blue rounded square). `Scripts/text_logo.py` generates them, so change
  the look there rather than hand-editing one SVG.
- Checked GroceryTracker at phone widths (360 and 390 CSS px) in Firefox 156 against a real API and a
  throwaway Postgres, with a year of imported bookings. Nothing scrolled sideways, but the wider
  monospace font caused four problems, all fixed in the same PR: `€` wrapped away from its amount
  (`Money` now joins them with a no-break space), dashboard tile figures broke over two lines (they
  now scale with the tile via `cqi` and never wrap), date fields cut off their year (opt-in
  `.field-row.wraps` stacks date and amount on phones), and Manage → People squeezed names to four
  letters (`.list-row.wraps` moves share and Remove to a second line).
- Layout-testing gotchas: Firefox won't size a window below ~500px and ignores `devPixelsPerPx` in
  headless mode, so a real 360px viewport needs the page in an iframe of that width. Element
  screenshots are clipped to the window height, so use a full-page screenshot of the outer page.
  Import only works after the device has synced once, so a layout check with data needs the API,
  not just the Blazor dev server.
- LaunchHeim now uses the repo's orange `#DE5833` as its accent and Kode Mono as its font on every
  platform. The window colours still follow Plasma or Windows. Qt 5 reads neither woff2 nor
  variable-font weights, so `Scripts/kodemono_static.py` cuts static Regular and Bold TTFs out of
  GroceryTracker's variable font. Gotcha: plain QML `Text` doesn't inherit the window font the way
  controls do, so `Badge`, `Avatar` and one drawer label needed `font.family` set explicitly. The
  sidebar logo is now the same "LH" SVG as the app icon.
- Rule from the owner: always make the SVG first and render raster files (PNG, .ico) from it, each
  size from the vector. Re-rendered LaunchHeim's `.ico` (16–256) and GroceryTracker's `favicon.ico`
  that way. GroceryTracker's PNG icons were already byte-identical.
- Started [[app-site]]: a GitHub Pages site in `site/` promoting GroceryTracker and LaunchHeim, with
  downloads, install guides and Ko-fi. Plus release automation
  ([[0007-per-app-releases-and-prebuilt-images]]): multi-arch GroceryTracker images on GHCR with an
  image-only `deploy/release/compose.yaml` (tested locally from an empty folder: healthy, synced, and
  it refuses to start without a password), and a LaunchHeim release workflow. `build-packages.sh`
  gained an `arch` format.
- Gotchas: in zsh `$n:localtest` applies the `:l` modifier (use `${n}:localtest`); `podman untag IMAGE`
  with no name drops every tag of that image; `pkill -f <pattern>` kills its own shell when the
  pattern is in the same command line.
- The owner chose MIT for [[grocerytracker]] too. Added its `LICENSE`, copied into all three images and
  attached to releases, with the OCI `licenses` label, and shown on the site.
