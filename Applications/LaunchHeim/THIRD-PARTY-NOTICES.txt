Qt 5.15
------------------------------------------------------------------------------

LaunchHeim uses the Qt library, version 5.15, for its user interface. Qt is Copyright (C) The Qt
Company Ltd. and other contributors, and is used here under the GNU Lesser General Public License
version 3 (licenses/LGPL-3.0.txt), which builds on the GNU General Public License version 3
(licenses/GPL-3.0.txt). Qt's own site: https://www.qt.io

The Windows zip contains the unmodified Qt 5.15.2 MSVC 2019 64-bit binaries (the Qt5*.dll files
and the plugin folders next to LaunchHeim.exe). The corresponding source code is available from
the Qt Project:

  https://download.qt.io/archive/qt/5.15/5.15.2/single/qt-everywhere-src-5.15.2.tar.xz

If that download ever stops working, open an issue at
https://github.com/CodeIsNotEvil/MyMonoRepo/issues and you will be sent the source.

LaunchHeim links Qt dynamically. To use a modified Qt, build Qt 5.15 with MSVC 2019 for x64 and
replace the DLLs and plugin folders next to LaunchHeim.exe with yours; nothing in LaunchHeim stops
this. The Linux packages use the distribution's Qt, which you can replace in the same way.

A copy installed with install.sh (or a development build) downloads a Qt 5.15.1 runtime published by
the Qml.Net project into ~/.qmlnet-qt-runtimes on first start. That copy comes from Qml.Net, under
the same LGPL-3.0 terms: https://github.com/qmlnet/qt-runtimes

Qt contains code from other projects, compiled into the Qt DLLs. Their notices and licenses are in
licenses/Qt-third-party.txt. Two of them ask for this credit:

  This software is based in part on the work of the Independent JPEG Group.

  Portions of this software are copyright (C) 2019 The FreeType Project (www.freetype.org).
  All rights reserved.

The Windows zip also contains ANGLE (libEGL.dll, libGLESv2.dll, BSD-3-Clause; part of Qt and listed
in licenses/Qt-third-party.txt) and opengl32sw.dll, a software OpenGL renderer built from Mesa 11.2.2
and LLVM (MIT and University of Illinois/NCSA, see licenses/Mesa-llvmpipe.txt).

Its native part (libQmlNet.so on Linux, QmlNet.dll on Windows) comes from qmlnet-native, the
