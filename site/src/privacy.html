LaunchHeim privacy policy

Last updated: 9 October 2026

LaunchHeim is a free, open-source mod launcher for Valheim, developed by CodeIsNotEvil. This policy explains what LaunchHeim does with your information.

In short: LaunchHeim has no accounts, no analytics, no telemetry and no ads. The developer receives no data from you. LaunchHeim only contacts other services when you use a feature that needs them.

1. Data stored on your device

LaunchHeim keeps everything it needs locally, in your user profile (on Windows %APPDATA%\LaunchHeim and %LOCALAPPDATA%\LaunchHeim; on Linux ~/.config/LaunchHeim, ~/.local/share/LaunchHeim, ~/.local/state/LaunchHeim and ~/.cache/LaunchHeim):

  • Settings, including any Nexus Mods or CurseForge API keys you enter, passwords you save for Valheim servers, and the choices you make per server or world.
  • Instances: mods, configuration files, and the icons and pictures you pick.
  • A log file that records what LaunchHeim did, such as installs, game launches and errors, to help with troubleshooting. It contains file paths, which may include your user name. Server passwords are removed before anything is written to the log.

This data never leaves your device unless you send it somewhere yourself, for example by sharing a modpack file or attaching the log to a bug report. Uninstalling LaunchHeim keeps your instances and settings; delete the folders above to remove them.

2. Files LaunchHeim reads but does not send

To show your characters, worlds, servers and screenshots, and to start the game, LaunchHeim reads Valheim's save files and server lists, Steam's library and log files, and your Steam screenshots. It only reads them on your device and never uploads them.

3. Online services LaunchHeim connects to

LaunchHeim connects to the services below only to provide the feature named. Each connection reveals your IP address and LaunchHeim's version (in the User-Agent header) to that service. Their own privacy policies apply to what they do with it.

  • Thunderstore (thunderstore.io): the list of Valheim mods, mod downloads and mod icons.
  • Nexus Mods (nexusmods.com): browsing mods and, if you enter your API key, downloading them. The key is sent only to Nexus Mods.
  • CurseForge (curseforge.com): only if you enter an API key, which is then sent only to CurseForge.
  • GitHub (github.com): checking for new LaunchHeim versions at start and twice a day, and downloading an update when you ask for one. These requests are anonymous.
  • Valheim servers in your server lists: a status query to each server you see on the Play page, to show how many players are online.
  • Steam: LaunchHeim starts Steam on your computer to launch Valheim. It sends nothing to Steam itself.

4. Phone sync on your local network

This feature is off unless you switch it on in Settings, or while the "Send to phone" dialog is open. LaunchHeim then announces itself on your local network with a device name (your computer's name unless you change it) and a random identifier, so the LaunchHeim Companion app and LocalSend can find it.

Mod lists and the server list are transferred directly between your devices over your local network, without any internet service in between. Nothing is accepted without your confirmation. These transfers are not encrypted, so use phone sync only on networks you trust. Server passwords are never sent.

5. Sharing with friends

When you use "Share with a friend", LaunchHeim writes a modpack file to your device. You decide where it goes, for example by dragging it into a chat. The file contains the instance's mod list and its configuration files.

6. Children

LaunchHeim does not knowingly collect personal information from anyone, including children.

7. Changes

If this policy changes, the new version will be published on this page with the date above. The source code, where you can verify all of this, is on GitHub.

8. Contact

Questions about this policy: open an issue on GitHub or email codeisnotevil@gmail.com.
