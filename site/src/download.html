GroceryTracker

Version {{ gt_version }} · released {{ gt_date }} · what's new · release notes · MIT license

No release yet · MIT license

GroceryTracker runs on a computer in your home, such as a Raspberry Pi 4 or 5, a NAS or any Linux machine, and every phone and laptop in the household uses it in the browser. It comes as ready-made containers for x86-64 and ARM64, so there is nothing to build.

Keep it at home. GroceryTracker has no login: anyone who can reach it can read and change everything. Use it on your home network or over a VPN such as Tailscale, and don't open it to the internet.

You need

  • A Linux machine that stays on (x86-64 or ARM64).
  • Podman with podman compose, or Docker with its Compose plugin.

Install

  1. Make a folder for it and download the two setup files: 
    mkdir grocerytracker && cd grocerytracker
curl -LO {{ gt_compose_url }}
curl -LO {{ gt_env_url }}
  2. Create your settings and choose a database password: 
    cp env.example .env
nano .env        # set POSTGRES_PASSWORD
  3. Start it. The first start downloads the images: 
    podman compose up -d        # or: docker compose up -d
  4. Open http://<your-machine>:8080 on any device in your home.

Update

podman compose pull && podman compose up -d

Your data stays in its own volume, and database changes are applied automatically when the new version starts. To stay on one version until you choose to update, set GROCERYTRACKER_VERSION={{ gt_version }} in .env.

The first release with prebuilt containers is on its way. Until then you can build it from source with the Raspberry Pi guide.

Install it on your phone (HTTPS)

Browsers only let you install GroceryTracker as an app, and use it offline, over HTTPS. Put a certificate named grocerytracker.crt with its key grocerytracker.key in a certs folder next to compose.yaml. It is then served on port 8443. The HTTPS guide shows how to make a certificate your devices trust.

First steps

  1. Manage: add the people who share the groceries, and your stores and categories.
  2. Trips → Add trip: record a shopping trip with its total and who paid. Line items are optional and split the total across categories.
  3. Dashboard: see your spending for this month, 3, 6 or 12 months, and per category and store.
  4. Balance: see who owes whom, and record a transfer when you settle up.
  5. Coming from a spreadsheet? Manage → Import bookings from CSV brings in your history. Importing the same file again never creates duplicates.

Everything works offline and syncs when the server is reachable again. More in the GroceryTracker README.

A Valheim mod launcher. Each instance is its own modpack with its own BepInEx, mods and configs, and the game install stays vanilla. You need Valheim on Steam.

LaunchHeim is MIT licensed and built on open-source software, including Qt 5.15 under the GNU LGPL v3. Every download contains THIRD-PARTY-NOTICES.txt and the license texts (read them online). The Qt in the Windows setup and zip is the unmodified Qt 5.15.2; its source is at download.qt.io.

Install

Windows 10 and 11

Run the setup. It installs LaunchHeim for you only (no administrator needed) or for all users, and asks whether you want a Start menu entry and a desktop shortcut. Windows doesn't know our certificate, so "Windows protected your PC" needs More info → Run anyway.

When a new version is out, LaunchHeim says so in its sidebar: click it, then Update now, and it installs the new version and starts again. Running a newer setup yourself works too. Your instances stay in %LOCALAPPDATA%\LaunchHeim, also when you uninstall it (Windows Settings → Apps).

To check the download, run this in PowerShell in the folder you saved it to. It prints True when the file is intact.

(Get-FileHash .\{{ lh_windows_setup_file }}).Hash -eq "{{ lh_windows_setup_sha256 }}"

The setup and LaunchHeim's own files are signed by CodeIsNotEvil with a self-signed certificate. That doesn't make Windows trust it, but it shows the files are ours and unchanged. This prints True:

(Get-AuthenticodeSignature .\{{ lh_windows_setup_file }}).SignerCertificate.Thumbprint -eq "284F5384B189984492629622EDC4A40646C5D8F6"

Rather not install anything? The portable zip has the same files: unzip it anywhere and start LaunchHeim.exe. To update it, replace the folder.

Windows 10 and 11

Unzip it anywhere, for example into %LOCALAPPDATA%\Programs, and start LaunchHeim.exe. Nothing else is needed. To update, replace the folder; your instances are kept in %LOCALAPPDATA%\LaunchHeim.

To check the download, run this in PowerShell in the folder you saved it to. It prints True when the file is intact.

(Get-FileHash .\{{ lh_windows_file }}).Hash -eq "{{ lh_windows_sha256 }}"

Releases after 0.5.2 are signed by CodeIsNotEvil with a self-signed certificate. Windows doesn't know it, so it still calls the publisher unknown, and "Windows protected your PC" needs More info → Run anyway. The signature shows the files are ours and unchanged; in the unzipped folder this prints True:

(Get-AuthenticodeSignature .\LaunchHeim\LaunchHeim.exe).SignerCertificate.Thumbprint -eq "284F5384B189984492629622EDC4A40646C5D8F6"
Arch Linux, CachyOS 
curl -LO {{ lh_arch_url }}
echo "{{ lh_arch_sha256 }}  {{ lh_arch_file }}" | sha256sum -c
sudo pacman -U ./{{ lh_arch_file }}

The package isn't signed, so pacman won't install it straight from the link; download it first. sha256sum -c prints OK when the file matches the release. Qt 5 and .NET come from the official repositories.

To update, run the same commands for the new version. pacman -Syu doesn't see new releases, because LaunchHeim isn't in a repository. To build it yourself instead, run makepkg -si in Applications/LaunchHeim/packaging/arch.

To update, run the same commands for the new version.

Android companion app

LaunchHeim Companion keeps your instances' mod lists on the phone: browse Thunderstore, Nexus Mods and CurseForge on the way and add mods, see who's online on your servers, and send the lists back to LaunchHeim at home. It needs Android 8 or newer and isn't in the Play Store.

  1. Open the download link above on the phone and open the file when it's done.
  2. Android asks to allow installing apps from your browser (or file manager) the first time. Allow it, go back, and install.
  3. On the PC, turn on Settings → Phone sync, then Library → Send to phone. Keep both on the same Wi-Fi.

To check the file on a PC first:

curl -LO {{ lh_android_url }}
echo "{{ lh_android_sha256 }}  {{ lh_android_file }}" | sha256sum -c

To update, install the new APK over the old one; your lists are kept. Apps such as Obtainium can watch the GitHub releases and update it for you.

The first release is on its way. Until then, the packaging guide shows how to build it for Arch (makepkg -si), Debian, Fedora and Windows.

First steps

  1. LaunchHeim finds Valheim through your Steam libraries. If it doesn't, pick the folder under Settings → Game.
  2. Library → New instance. BepInEx is installed into it for you.
  3. Browse mods, pick the instance under Install into, and install. Dependencies come along automatically.
  4. Press Play on the instance, or join a server or load a world from the Play page with a character and setup it remembers. The sidebar's play button starts whatever you played last.
  5. Already modded by hand? Import game folder turns it into an instance and leaves the original alone.
  6. On the go: Send to phone puts your instances on the Android companion. Add mods there, and when you're home, send the list back. LaunchHeim shows what changed and updates the instance, or imports it as a new one.
Nexus Mods and CurseForge

Thunderstore works right away. For Nexus Mods, add your personal API key under Settings and press Register, so the website's "Mod Manager Download" buttons open LaunchHeim. Premium accounts can install straight from LaunchHeim. For CurseForge, add a free API key from the CurseForge for Studios console.

What happens to my game folder?

On Linux, nothing: each instance's BepInEx is loaded from the instance folder. On Windows, BepInEx's loader (winhttp.dll) has to sit next to the game, so LaunchHeim puts it there, switched off. Starting Valheim from Steam stays vanilla. Delete that file and doorstop_config.ini to remove it.
