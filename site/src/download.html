GroceryTracker

Version {{ gt_version }} · released {{ gt_date }} · what's new · release notes · MIT license

No release yet · MIT license

GroceryTracker runs on a computer in your home, such as a Raspberry Pi 4 or 5, a NAS or any Linux machine, and every phone and laptop in the household uses it in the browser. It comes as ready-made containers for x86-64 and ARM64, so there is nothing to build.

Download and install

Keep it at home. GroceryTracker has no login: anyone who can reach it can read and change everything. Use it on your home network or over a VPN such as Tailscale, and don't open it to the internet.

You need

  • A Linux machine that stays on (x86-64 or ARM64).
  • Podman with podman compose, or Docker with its Compose plugin.

Install

  1. Make a folder for it and download the two setup files: 
    mkdir grocerytracker && cd grocerytracker
curl -LO {{ gt_compose_url }}
curl -LO {{ gt_env_url }}
  2. Create your settings and choose a database password: 
    cp env.example .env
nano .env        # set POSTGRES_PASSWORD
  3. Start it. The first start downloads the images: 
    podman compose up -d        # or: docker compose up -d
  4. Open http://<your-machine>:8080 on any device in your home.

Update

podman compose pull && podman compose up -d

Your data stays in its own volume, and database changes are applied automatically when the new version starts. To stay on one version until you choose to update, set GROCERYTRACKER_VERSION={{ gt_version }} in .env.

The first release with prebuilt containers is on its way. Until then you can build it from source with the Raspberry Pi guide.

Install it on your phone (HTTPS)

Browsers only let you install GroceryTracker as an app, and use it offline, over HTTPS. Put a certificate named grocerytracker.crt with its key grocerytracker.key in a certs folder next to compose.yaml. It is then served on port 8443. The HTTPS guide shows how to make a certificate your devices trust.

LaunchHeim

Version {{ lh_version }} · released {{ lh_date }} · what's new · release notes · MIT license

No release yet · MIT license

A Valheim mod launcher. Each instance is its own modpack with its own BepInEx, mods and configs, and the game install stays vanilla. You need Valheim on Steam.

Download and install
Get it from the Microsoft Store

For Windows 10 and 11. The Store installs the same setup you can download here, so it updates the same way: when a new version is out, LaunchHeim says so in its sidebar, and Update now installs it. Your instances stay in %LOCALAPPDATA%\LaunchHeim.

A new release can take a few days to reach the Store; the Windows setup tab always has the newest one.

Download the setup {{ lh_windows_setup_size }}

Run it. It installs LaunchHeim for you only (no administrator needed) or for all users. Windows doesn't know our certificate, so "Windows protected your PC" needs More info → Run anyway.

When a new version is out, LaunchHeim says so in its sidebar: Update now installs it and starts again. Your instances stay in %LOCALAPPDATA%\LaunchHeim, also when you uninstall it (Windows Settings → Apps).

Rather not install anything? The portable zip ({{ lh_windows_size }}) has the same files: unzip it anywhere and start LaunchHeim.exe. To update it, replace the folder.

Check the download

In PowerShell, in the folder you saved it to. This prints True when the file is intact:

(Get-FileHash .\{{ lh_windows_setup_file }}).Hash -eq "{{ lh_windows_setup_sha256 }}"

The setup and LaunchHeim's own files are signed by CodeIsNotEvil with a self-signed certificate. That doesn't make Windows trust it, but it shows the files are ours and unchanged. This prints True:

(Get-AuthenticodeSignature .\{{ lh_windows_setup_file }}).SignerCertificate.Thumbprint -eq "284F5384B189984492629622EDC4A40646C5D8F6"
curl -LO {{ lh_arch_url }}
echo "{{ lh_arch_sha256 }}  {{ lh_arch_file }}" | sha256sum -c
sudo pacman -U ./{{ lh_arch_file }}

The package isn't signed, so pacman won't install it straight from the link; download it first. sha256sum -c prints OK when the file matches the release. Qt 5 and .NET come from the official repositories.

To update, run the same commands for the new version. pacman -Syu doesn't see new releases, because LaunchHeim isn't in a repository. To build it yourself instead, run makepkg -si in Applications/LaunchHeim/packaging/arch.

For Debian 13, Ubuntu 24.04 and newer:

curl -LO {{ lh_deb_url }}
echo "{{ lh_deb_sha256 }}  {{ lh_deb_file }}" | sha256sum -c
sudo apt install ./{{ lh_deb_file }}

To update, run the same commands for the new version.

For Fedora, RHEL 9 and 10:

curl -LO {{ lh_rpm_url }}
echo "{{ lh_rpm_sha256 }}  {{ lh_rpm_file }}" | sha256sum -c
sudo dnf install ./{{ lh_rpm_file }}

On RHEL 10 and its rebuilds, enable EPEL first (sudo dnf install epel-release), which still has Qt 5. To update, run the same commands for the new version.

Download the APK {{ lh_android_size }}

LaunchHeim Companion keeps your instances' mod lists on the phone: browse Thunderstore, Nexus Mods and CurseForge on the way and add mods, see who's online on your servers, and send the lists back to LaunchHeim at home. It needs Android 8 or newer and isn't in the Play Store.

  1. Open this page on the phone, tap the download, and open the file when it's done.
  2. Android asks to allow installing apps from your browser (or file manager) the first time. Allow it, go back, and install.
  3. On the PC, turn on Settings → Phone sync, then press the phone button on an instance's page. Keep both on the same Wi-Fi. If the phone can't find the PC, Settings → Phone sync shows how to let it through the firewall.

To update, install the new APK over the old one; your lists are kept.

Updates with Obtainium
  1. In Obtainium, tap Add App and enter {{ repo_url }} as the source URL.
  2. Set Filter release titles by regular expression to ^LaunchHeim. The repository also releases GroceryTracker, which has no APK.
  3. Tap Add. Obtainium recognises the installed companion and installs new versions when they come out.
Check the file on a PC first

Nexus Mods and CurseForge

Thunderstore works right away. For Nexus Mods, copy the API key Nexus lists for Vortex on your API keys page into Settings and press Register, so the website's "Mod Manager Download" buttons open LaunchHeim. Premium accounts can install straight from LaunchHeim. CurseForge doesn't let other apps download Valheim mods: download them on CurseForge and drop the file onto an instance.

What happens to my game folder?

On Linux, nothing: each instance's BepInEx is loaded from the instance folder. On Windows, BepInEx's loader (winhttp.dll) has to sit next to the game, so LaunchHeim puts it there, switched off. Starting Valheim from Steam stays vanilla. Delete that file and doorstop_config.ini to remove it.

Why does Steam start the game on Windows?

On Windows, LaunchHeim asks Steam to start Valheim with the instance's settings, because Steam only adds its overlay (Shift+Tab, F12 screenshots) to games it starts itself. So the launch options in Valheim's Steam properties apply too. On Linux, LaunchHeim starts the game itself and loads the overlay the same way Steam does.
